# Headlamp Integration — Implementation Plan

## Context

KKP needs to integrate Headlamp as a seed-side per-user-cluster deployment, mirroring the
existing kubernetes-dashboard pattern. Headlamp works out-of-cluster with a mounted kubeconfig
(-kubeconfig flag, port 4466).

Spec:  docs/superpowers/specs/2026-03-31-headlamp-integration-design.md
Issue: https://github.com/kubermatic/kubermatic/issues/15287


## Implementation Phases

=== Phase 1: API Types & Constants ===

Files to modify:

1. sdk/apis/kubermatic/v1/cluster.go — Add new types and methods:

   // Headlamp struct (near KubernetesDashboard struct, ~line 288)

=== Phase 2: Seed-Side Resources ===

Files to create:

1. pkg/resources/headlamp/deployment.go — Seed-side Deployment reconciler
   - Mirror structure of pkg/resources/kubernetes-dashboard/deployment.go
   - headlampData interface: Cluster(), RewriteImage()
   - DeploymentReconciler(data) -> NamedDeploymentReconcilerFactory
   - Image: ghcr.io/headlamp-k8s/headlamp:v0.26.0
   - Command: ["/headlamp/headlamp-server"]
   - Args: ["-kubeconfig", "/etc/kubernetes/kubeconfig/kubeconfig", "-html-static-dir", "/headlamp/frontend"]
   - Port: 4466
   - 2 replicas, anti-affinity, apiserver.IsRunningWrapper
   - SecurityContext: runAsUser 100, runAsGroup 101, readOnlyRootFilesystem, no privilege escalation
   - Resources: cpu 100m/250m, memory 128Mi/256Mi
   - Volume mounts: kubeconfig secret + tmp emptydir
   - ImagePullSecrets, restart annotation, autoscaler annotation

2. pkg/resources/headlamp/deletion.go — Seed-side deletion
   - ResourcesForDeletion(namespace string) []ctrlruntimeclient.Object
   - Returns: Deployment + kubeconfig Secret

## Local Testing

Prerequisites:
  - ~/.kube/dev.kubeconfig pointing to the dev seed cluster
  - A running user cluster on that seed (e.g. v99jth46cb)

Step 1: Label the test cluster
-------
  export KUBECONFIG=~/.kube/dev.kubeconfig
  export TEST_CLUSTER=v99jth46cb

  # NOTE: hack/run-seed-controller-manager.sh sanitizes worker-name (strips non-alphanumeric)
  # "headlamp-local-test" becomes "headlamplocaltest"
  kubectl label cluster $TEST_CLUSTER worker-name=headlamplocaltest --overwrite

  # Enable headlamp explicitly
  kubectl patch cluster $TEST_CLUSTER --type=merge -p '{"spec":{"headlamp":{"enabled":true}}}'

Step 2: Run seed-controller-manager with log file
-------
  cd /Users/mac/Work/Github/kubermatic/kkp.worktree/headlamp-migration

  KUBERMATIC_WORKERNAME=headlamplocaltest \
    ./hack/run-seed-controller-manager.sh 2>&1 | tee /tmp/headlamp-controller.log

  # In another terminal:
  tail -f /tmp/headlamp-controller.log
  grep -i headlamp /tmp/headlamp-controller.log

Step 3: Verify
-------
  export KUBECONFIG=~/.kube/dev.kubeconfig

  # Watch for headlamp deployment + secret
  watch kubectl -n cluster-v99jth46cb get deploy,secret 2>&1 | grep headlamp

  # Port-forward and open UI
  kubectl -n cluster-v99jth46cb port-forward deploy/headlamp 4466:4466
  # Open http://localhost:4466

  # Check health status
  kubectl get cluster v99jth46cb -o jsonpath='{.status.extendedHealth.headlamp}'

Step 4: Test disable
-------
  kubectl patch cluster $TEST_CLUSTER --type=merge -p '{"spec":{"headlamp":{"enabled":false}}}'
  kubectl -n cluster-v99jth46cb get deploy,secret | grep headlamp
  # Should return nothing

Cleanup:
-------
  kubectl label cluster $TEST_CLUSTER worker-name-
  kubectl patch cluster $TEST_CLUSTER --type=merge -p '{"spec":{"headlamp":null}}'
  rm -f /tmp/headlamp-controller.log
